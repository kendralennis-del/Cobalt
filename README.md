✨ Features
🚀 Written from scratch in C++23 (no code from the vanilla server)
⚡ Low memory footprint and fast startup
🌐 Asynchronous networking
🧵 Multithreaded chunk handling
🔌 Protocol support for Minecraft Java Edition X.XX.X
🌍 World generation and chunk loading/saving
👥 Multiplayer with player join/leave, chat, and movement
🧩 Modular architecture, easy to extend
